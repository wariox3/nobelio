# Listas de nómina electrónica

La DIAN no publica en Genericode las cuatro listas propias de la nómina
electrónica: solo están en el PDF del *Anexo Técnico de Nómina Electrónica*
(Resolución 000013 de 2021), numeral 5.5. Se transcribieron aquí a `.gc`, con
los acentos corregidos, para que se carguen como cualquier otro catálogo (ver el
README de la carpeta padre).

| Archivo | Numeral | Modelo |
|---------|---------|--------|
| `PeriodoNomina.gc` | 5.5.1 | `PeriodoNomina` |
| `TipoContrato.gc` | 5.5.2 | `TipoContrato` |
| `TipoTrabajador.gc` | 5.5.3 | `TipoTrabajador` |
| `SubTipoTrabajador.gc` | 5.5.4 | `SubTipoTrabajador` |

No son copia de un archivo oficial, así que no hay versión nueva que reemplazar:
si el anexo cambia, se editan a mano. Como en las demás, cada fila lleva su
`id` fijo.
